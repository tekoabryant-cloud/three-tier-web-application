# Three-Tier Web Application

## Project Overview

This project demonstrates a three-tier web application architecture using AWS cloud services.

The application is divided into three main layers:

1. Presentation Tier
2. Application Tier
3. Database Tier

## Architecture

User
↓
Presentation Tier
↓
Application Tier
↓
Database Tier

## AWS Services

- Amazon VPC
- Amazon EC2
- Amazon RDS
- Application Load Balancer
- Security Groups
- IAM
- Amazon CloudWatch

## Project Goals

- Build a secure three-tier architecture
- Separate the web, application, and database layers
- Configure networking and security between tiers
- Deploy and test the application
- Monitor the environment with CloudWatch

## Status

Completed — Local three-tier application developed, AWS architecture configured and tested, and project documented in GitHub. Live AWS compute resources were terminated after testing to avoid ongoing charges.
